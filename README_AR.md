# All Edit — دليل التشغيل والنشر

## التشغيل المحلي
```bash
npm install --ignore-scripts   # الخيار يتجنب سكربت تحميل غير لازم في المتصفح
npm run dev                    # افتح الرابط في Chrome أو Edge
```
قبل `dev` و`build` تعمل تلقائياً ثلاثة سكربتات (في `scripts/`): تقسيم ملف ONNX WASM، وتوليد صفحة التراخيص، وتوليد صفحتي الخصوصية والشروط ببريدك.

## ما تغيّر في بناء الكابشن (مشكلة ملف WASM الكبير)
- ملف `ort-wasm-simd-threaded.asyncify.wasm` حجمه **25.6 MiB** وهو أكبر من حد Cloudflare Workers Assets (25 MiB).
- الآن لا يدخل `dist` أبداً (إضافة `drop-wasm` في `vite.config.ts`). يُقسَّم إلى أجزاء (~8.5 MiB) في `dist/ort/`، ويجمّعها الـ Worker ويمرّرها لمحرك ONNX مباشرة (`wasmBinary`)، فلا CDN ولا ملف كبير، ويعمل بدون إنترنت بعد أول تحميل.
- `npm run build` يفشل تلقائياً (`scripts/check-dist.mjs`) إن ظهر ملف أكبر من 24 MiB أو أي `.wasm` أو غاب `dist/ort/manifest.json`.
- جرّبتُ الآلية بنموذج ONNX حقيقي في متصفح Chromium (النتيجة صحيحة)، وتأكدت أن الـ Worker داخل التطبيق يجلب الأجزاء من نفس الموقع.

## النشر على Cloudflare
```bash
npm run build
npx wrangler deploy      # يقرأ wrangler.jsonc (assets: ./dist)
```
- `public/_headers` يضبط الكاش والأمان. بعد النشر تأكد أن `/.well-known/assetlinks.json` يعرض JSON.
- Git على Windows: `.gitattributes` يثبّت نهايات الأسطر LF لتختفي تحذيرات LF/CRLF. و`.gitignore` يستبعد الملفات المولّدة (`public/ort` والصفحات المولّدة و`dist`).

## قبل النشر على Google Play
1. عدّل `contactEmail` في `src/config.ts`.
2. اتبع `docs/PLAY-STORE-AR.md` خطوة بخطوة (API 36، assetlinks، سلامة البيانات، التصنيف…).
3. نصوص المتجر والرسومات في `store/`.

## الدارجة المغربية
اقرأ `docs/DARIJA-ONNX.md`: كيف يعمل الوضع الحالي، وكيف تضيف نموذجاً مدرَّباً على الدارجة.

## اختبارات سريعة
- التصدير: الجودة «سريع» (720p) ثم «عالٍ». بعد كل تصدير تُعرض سرعته وهل استُخدم الترميز بالعتاد.
- الحساب ← «حالة جهازك» يفحص دعم المتصفح.

## التصدير على الهاتف
- **الكتابة على القرص:** الملف يُكتب مباشرة في مساحة التطبيق الخاصة (OPFS) بدل تجميعه في الذاكرة، فلا ينهار مع الفيديوهات الطويلة. وإن لم يدعمه المتصفح يعود تلقائياً للذاكرة.
- **الصوت:** صوت AAC في ملفات MP4/MOV يُنسخ كما هو دون فك ترميز، فلا يلزم مرمّز AAC، وأسرع وأخف (إزاحة تقارب 25 ميلي ثانية بسبب تأخير AAC المعتاد). للصيغ الأخرى يُستخدم المسار القديم.
- **الجودة الافتراضية «سريع» (720p)** على الهواتف، والعتاد يُطلب أولاً.
- الشاشة تبقى مضاءة أثناء التصدير ويُعاد طلب القفل عند العودة للتطبيق، وتظهر رسالة إن غادرت الصفحة.
- بعد التصدير: «مشاركة / حفظ في المعرض» أولاً على الهواتف، و«تنزيل الملف» بديلاً. الملفات المؤقتة تُحذف عند الإغلاق أو الإلغاء.
