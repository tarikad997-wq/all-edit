# استبيان تصنيف المحتوى (IARC) — إجابات مقترحة

- الفئة: **أداة / إنتاجية / أخرى**
- العنف، الدم، المحتوى الجنسي، لغة نابية، مخدرات، قمار، مواضيع مخيفة: **لا** لكل البنود
- هل يتيح التطبيق للمستخدمين التواصل أو مشاركة المحتوى مع آخرين داخل التطبيق؟ **لا**
- هل يشارك موقع المستخدم؟ **لا** — هل يسمح بالشراء الرقمي؟ **لا**
- المتوقع: تصنيف عام لكل الأعمار (يحدده الاستبيان وليس نحن).
