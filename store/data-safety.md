# نموذج «سلامة البيانات» (Data safety) — الإجابات المقترحة

| السؤال | الإجابة |
|---|---|
| هل يجمع تطبيقك أو يشارك أياً من أنواع بيانات المستخدم المطلوبة؟ | **لا** |
| هل كل بيانات المستخدم مشفّرة أثناء النقل؟ | غير منطبق (لا تُنقل بيانات مستخدم) |
| هل توفّر طريقة لطلب حذف البيانات؟ | غير منطبق (لا حساب). مع ذلك يوفّر التطبيق زر «مسح كل بياناتي من هذا الجهاز» |
| هل يتبع التطبيق سياسة العائلات؟ | لا (الجمهور 13+) |

**ملاحظات تبرّر «لا»:** الصور والفيديوهات والصوت تُعالج على الجهاز ولا تُرسل؛ لا حسابات؛ لا SDK للإعلانات أو التحليلات؛ طلب الشبكة الوحيد هو تنزيل نموذج التعرف على الكلام من Hugging Face (لا يتضمن بيانات المستخدم).
**تنبيه:** إن أضفتَ لاحقاً أي تحليلات أو إعلانات أو تسجيل دخول فحدّث هذا النموذج وسياسة الخصوصية.
